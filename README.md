
# House Price Prediction using Linear Regression

## Project Overview
This project uses a Linear Regression machine learning model to predict house prices based on square footage, number of bedrooms, and number of bathrooms.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
Kaggle - House Prices: Advanced Regression Techniques

https://www.kaggle.com/c/house-prices-advanced-regression-techniques/data

## Algorithm
Linear Regression

## Features
- Living Area (square feet)
- Number of Bedrooms
- Total Bathrooms

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R2 Score
